# 💎 VELOOP Exchange Center

A premium and responsive redesign of the VELOOP Rewards Exchange Center, focused on converting earned Gems into VEs through a simple, trustworthy, and interactive reward experience.

## ✨ Features

* 💎 Gems → VEs reward conversion
* 💰 User balance overview
* 🔄 Multiple conversion opportunities
* ✅ Conversion confirmation modal
* ⚠️ Insufficient Gems state
* 🎉 Successful conversion state
* ⏳ Loading and error states
* 📜 Recent conversion history
* 📖 Exchange rules
* 📱 Fully responsive design
* ✨ Smooth UI animations and interactions

## 🛠️ Tech Stack

* React.js
* Vite
* Bootstrap
* CSS Modules
* React Hooks
* React Icons
* Framer Motion

## 🚀 Installation

```bash
git clone <repository-url>
cd veloop-exchange-center
npm install
npm run dev
```

## 🎯 Concept

The Exchange Center is designed as a **Reward Conversion Center**, not a cryptocurrency trading interface. Users can review available conversions, confirm an exchange, and receive VEs from their earned Gems.

## 📂 Architecture

The project uses reusable React components, structured exchange data, CSS Modules, and a component-based architecture to keep the frontend clean and ready for future backend integration.

## 📱 Responsive Design

The interface is designed for mobile, tablet, laptop, desktop, and large-screen layouts.

## 🔮 Future Integration

The frontend is structured to support future API integration for:

* User balances
* Exchange opportunities
* Conversion processing
* Conversion history
* Loading and error states
